# SLICE 2026 College Symposium Website Design Specification

A premium, modern, and high-performance single-page web portal for the **SLICE 2026** college symposium. Built from scratch using clean, semantic HTML5, custom CSS (vanilla style sheets with modern design tokens), and interactive Vanilla JavaScript. 

The website will be hosted on Vercel for free, linked directly to a GitHub repository, and optimized to handle 1000+ visitors with ease.

---

## 1. Brand Identity & Visual Design Tokens
To make the site look premium and state-of-the-art:
- **Aesthetic Style:** Dark mode futuristic design with glassmorphism panels (translucent cards with thin glowing borders) and neon accents.
- **Colors:**
  - **Background:** Midnight Blue / Deep Black-Slate (`#0B0F19`)
  - **Card Background:** Semi-transparent Glass (`rgba(20, 26, 45, 0.6)`) with a subtle backdrop-filter blur.
  - **Primary Neon Highlight:** Electric Cyan (`#00F2FE`)
  - **Secondary Neon Highlight:** Neon Purple/Indigo (`#4FACFE`)
  - **Text Colors:** Crisp White (`#FFFFFF`) for primary titles, Light Gray (`#94A3B8`) for body copy.
- **Typography:** Google Fonts pairing:
  - **Headings:** *Outfit* (bold, futuristic sans-serif)
  - **Body text:** *Inter* (highly readable, clean)

---

## 2. Page Structure & Components
The site will be structured as a smooth-scrolling single page with the following sections:

### 2.1. Navigation Bar (Sticky Header)
- Translucent glassmorphism bar at the top of the page.
- Logo/Text: **SLICE 2026**
- Smooth-scrolling links to: `Home`, `About`, `Events`, `Schedule`, `FAQs`, `Contact`.
- Accent CTA "Register Now" button in the corner.

### 2.2. Hero Section (First Impression)
- Large, bold title: `SLICE 2026` with a glowing text shadow or gradient fill.
- Subtitle: Department / College Symposium details & Date.
- **Under Construction Banner:** Displays the custom `assets/ece_under_construction.jpg` image to represent that the ECE department is setting up the site.
- **Countdown Timer:** Interactive JavaScript widget showing days, hours, minutes, and seconds remaining until the event.
- Call to Action: Glowing "Register Now" button anchoring directly to the registration info/Google Form.

### 2.3. About Section
- Brief introductory paragraph about the symposium, the department hosting it, and the theme of SLICE 2026.
- Key highlights (e.g., total cash prizes, certificate details, food/lunch inclusion).

### 2.4. Events & Workshops Section
- Tabbed selector: `All Events`, `Technical`, `Non-Technical`, `Workshops`.
- Responsive grid of cards.
- **Event Cards:**
  - Standard tech placeholder events:
    - *Technical:* Coding Quest (Speed coding), WebCraft (Web design), Paper Pitch (Paper presentation).
    - *Non-Technical:* Cyber Gaming (Valorant/BGMI), LensCraft (Photography), Mystery Hunt (Treasure hunt).
    - *Workshops:* Generative AI & Prompt Engineering, Cyber Security Hands-On.
  - Cards feature a title, brief summary, cash prize tag, and a "View Details" button.
- **Interactive Details Modal:** Clicking "View Details" pops open a modal/overlay showing the rules, team size guidelines, coordinator contact details, and a direct Google Forms registration button.

### 2.5. Timeline / Schedule
- Vertical layout depicting the schedule of the day (e.g., 8:30 AM Registration, 9:30 AM Inauguration, 10:30 AM Event Rounds, 1:00 PM Lunch, 2:00 PM Finals, 4:00 PM Valedictory).

### 2.6. FAQ Section
- Interactive accordion list.
- Questions covered: registration fees, team combinations, certificate issuance, food arrangements, on-spot registration policies.

### 2.7. Footer / Contact Details
- Contact information of student coordinators & faculty advisors (names, phone numbers).
- Integrated Google Map location frame placeholder.
- Social media icons (Instagram, LinkedIn, YouTube).
- Copyright footer.

## 3. Data Flow & Technical Behavior
1. **Interactive Event Cards:** Events are defined in a JS array inside `app.js` containing names, descriptions, rules, prizes, and coordinator info. The JS script dynamically renders the cards on page load, allowing easy maintenance and fast modifications when the actual details are finalized.
2. **Countdown Logic:** Running in the background with `setInterval`, updating the DOM every second. Handles timer expiration by displaying a "Symposium has Started!" message.
3. **Registration flow:** Registration buttons redirect to a Google Forms URL using target target="_blank".
4. **Active Navigation Highlighting:** IntersectionObserver API updates the active link in the navigation header as the user scrolls through different sections.

---

## 4. Verification & Testing Plan
1. **Responsiveness:** Visual checks on mobile (simulated iPhone/Android sizes), tablet, and desktop views.
2. **Performance:** Test page loading speed. Since it is built in pure HTML/CSS/JS without heavy frameworks, it should score ~95-100 on Google PageSpeed Insights.
3. **Interactivity Check:** Ensure modals open/close cleanly, FAQs expand/collapse correctly, and the countdown timer works without UI lag.
