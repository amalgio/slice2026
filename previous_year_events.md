## Astro Logiq
*Decode the Universe, One Gate at a Time*

**Description:** ASTRO LOGIQ is an engaging digital logic maze challenge that tests participants’ ability to trace and solve logic gate sequences. Teams will analyze how outputs from one gate connect as inputs to the next, making logical decisions to navigate through the maze and reach the final output correctly.

**Flow of Event:** 🪐Round 1: Signal Uplink (Logic Maze) Teams start with given binary inputs (e.g., 0 and 1). They are presented with a series of logic gates arranged like a maze. Each step involves applying the gate’s logic to current inputs and moving forward based on the result. If a gate requires two inputs but only one output is available from the previous gate, teams must decide how to provide the second input (e.g., reuse original inputs or choose another path). Teams record the output after each gate until reaching the maze end. Correct final output scores points; faster completion gains bonus points. Inputs: A = 0, B = 1 Gate 1: AND gate → Output = 0 AND 1 = 0 Gate 2: OR gate requires two inputs. Previous output is 0 (single input). Second input taken as B = 1 (original input). Output of Gate 2: 0 OR 1 = 1 🪐Round 2: Orbital Auction (Logic Auction) Teams receive a real-world logic problem to solve. They discuss and plan the Boolean expression within a limited time. Gates are auctioned; teams use points to bid and buy gates. Teams build the circuit using only gates they purchased. Correctness and cost efficiency are evaluated. 📱

## Stellar Quest
**Description:** Stellar Quest is a thrilling two-round, space-themed technical challenge for Electronics and Communication Engineering students.It tests logical reasoning, electronics knowledge, coding skills, and creativity.
